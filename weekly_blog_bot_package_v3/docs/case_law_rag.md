# 판례 DB RAG 운영 노트

`참조_판례_정리본.txt` 같은 대형 판례 DB는 통째로 모델 입력에 넣지 않는다.

## 원칙

- `never_inline_full_db: true`
- 기본은 외부 벡터 스토어
- 벡터 스토어가 없으면 `local_keyword_rag`로 최대 6건, 사건당 1,800자만 주입

## 이유

대형 DB를 매 호출에 통째로 넣으면 입력 토큰이 폭주한다. 컨텍스트 예산 가드는 `block_input_tokens: 200000`을 넘으면 실행을 중단하고 `payload_blocked` 알림을 보낸다.

## 운영 체크

- 분야 매칭 시에만 판례 검색
- 사건 ID, 카테고리, 법원, 선고일, 핵심 판단만 주입
- 원문 확인이 필요한 최신 판례·법령은 web search 또는 공식 원문으로 별도 확인

# 스킬트리 — 이 시스템으로 할 수 있는 일

말로 풀면 다음 다섯 가지를 합니다. 각 노드 끝의 **🔧 도구**는 MCP가 연결된 경우 자동 호출되는 도구 이름입니다.

```
세무기장대리 어시스턴트
│
├─ 📅 [1] 일정·체크리스트
│   ├─ "연간 세무 일정 보여줘 (개인 일반과세)"          🔧 get_tax_calendar
│   ├─ "샘플상사 30일 안에 마감 뭐 있어?"               🔧 get_upcoming_checklist
│   ├─ "법인 부가세 1기 예정 언제까지야?"               🔧 get_tax_calendar (필터 vat)
│   └─ "이번 달 해야 할 거 다 알려줘"                   🔧 get_upcoming_checklist(days=30)
│
├─ 🧮 [2] 즉석 계산 (DB 없이도 동작)
│   ├─ 부가세
│   │   └─ "매출 5천만, 매입 2천만 부가세?"             🔧 calc_vat
│   ├─ 종합소득세
│   │   └─ "사업소득 8천만, 4인 가족 종소세?"           🔧 calc_income_tax
│   ├─ 원천세
│   │   ├─ "프리랜서 200만원 지급 시 떼는 거?"          🔧 calc_withholding(type=BUSINESS)
│   │   └─ "강사료 50만원 기타소득 원천세?"             🔧 calc_withholding(type=OTHER)
│   └─ 4대보험
│       └─ "월 350만 받으면 4대보험 얼마?"              🔧 calc_insurance
│
├─ 📝 [3] 기장 (분개 입력) — 가장 핵심
│   ├─ "이 영수증으로 매입 분개 만들어줘" + 사진         🔧 create_journal_entry
│   │   (Claude 비전이 영수증 직접 읽음 → 확인 → 저장)
│   ├─ "ABC상사한테 5/12 100만원 매출 현금"             🔧 create_journal_entry
│   ├─ "면세사업자라 부가세 없이 입력해줘"               🔧 create_journal_entry(isTaxFree=true)
│   └─ "최근 매출 거래 5건 보여줘"                      🔧 list_recent_journal_entries
│
├─ 📊 [4] 신고 자료 / 집계
│   ├─ "1분기(1~3월) 부가세 자료 줘"                    🔧 get_client_vat_aggregate
│   ├─ "올해 누적 매출세액 얼마야?"                     🔧 get_client_vat_aggregate
│   └─ "납부세액 vs 환급세액 어느 쪽이야?"              🔧 get_client_vat_aggregate
│
└─ 🔧 [5] 고객사·관리
    ├─ "내가 관리하는 거래처 다 보여줘"                  🔧 list_clients
    ├─ "샘플상사 정보 알려줘"                            🔧 list_clients (필터)
    └─ "이 거래처 어떤 유형이야?"                        🔧 list_clients
```

## 입력 패턴 → 분기

사용자 메시지 → Claude가 자동으로 가지를 선택:

| 메시지 패턴 | 가지 | 후속 |
| --- | --- | --- |
| 사진/PDF 첨부 + "분개" | [3] | 비전 추출 → 사용자 확인 → 저장 |
| 숫자 + "부가세/소득세/원천세/4대보험" | [2] | 즉석 계산기 |
| "언제까지", "마감", "이번 달" | [1] | 일정 도구 |
| "신고 자료", "1분기 집계" | [4] | 기간 확인 → aggregate |
| "거래처", "고객사 누구" | [5] | 목록/상세 |
| 자연어 거래("○○ 한테 ××원 매출") | [3] | 분개 자동 생성 → 확인 → 저장 |

## 가지 사이 이동 예시

```
사용자: "샘플상사 이번 달 뭐 해야 해?"
  → [1] get_upcoming_checklist(샘플상사, 30)
  → "5/31 종소세 정기신고 D-19 임박"

사용자: "그럼 종소세 얼마쯤 나올까? 사업소득 7천만 가정"
  → [2] calc_income_tax(70000000, dependents=1)
  → "산출세액 ○○원, 지방세 포함 ○○원"

사용자: "5월 매출 합계 보고 다시 계산해줘"
  → [4] get_client_vat_aggregate(샘플상사, 2026-05-01, 2026-05-31)
  → [2] 그 결과로 calc_income_tax 재실행
```

# 시드 계정과목 (분개 시 사용)

`prisma/seed.ts`가 등록하는 12개 계정과목. `create_journal_entry` 도구의 표준 분개는 이 중 7개를 자동으로 사용합니다. 그 외 계정 사용 거래는 현재 수동 입력 안내.

## 자산 (ASSET)

| 코드 | 명칭 | 용도 |
| --- | --- | --- |
| 101 | 현금 | 표준 분개: 현금/보통예금 결제 |
| 102 | 보통예금 | (101과 묶어서 처리) |
| 108 | 외상매출금 | 표준 분개: 외상 매출 |
| 135 | 부가세대급금 | 표준 분개: 매입 부가세 |
| 146 | 상품 | 표준 분개: 매입 자산 |

## 부채 (LIABILITY)

| 코드 | 명칭 | 용도 |
| --- | --- | --- |
| 251 | 외상매입금 | 표준 분개: 외상 매입 |
| 255 | 부가세예수금 | 표준 분개: 매출 부가세 |

## 수익 (REVENUE)

| 코드 | 명칭 | 용도 |
| --- | --- | --- |
| 401 | 상품매출 | 표준 분개: 매출 수익 |

## 비용 (EXPENSE)

| 코드 | 명칭 | 용도 |
| --- | --- | --- |
| 451 | 상품매출원가 | 수동 (재고 평가 시) |
| 811 | 복리후생비 | 수동 |
| 813 | 접대비 | 수동 |
| 814 | 통신비 | 수동 |

## 표준 분개 패턴

### 매출 + 현금/보통예금
```
차변 101 현금              (공급가액 + 부가세)
대변 401 상품매출          (공급가액)
대변 255 부가세예수금       (부가세)  ← 면세면 생략
```

### 매출 + 외상
```
차변 108 외상매출금        (공급가액 + 부가세)
대변 401 상품매출          (공급가액)
대변 255 부가세예수금       (부가세)  ← 면세면 생략
```

### 매입 + 현금/보통예금
```
차변 146 상품              (공급가액)
차변 135 부가세대급금       (부가세)  ← 면세면 생략
대변 101 현금              (공급가액 + 부가세)
```

### 매입 + 외상
```
차변 146 상품              (공급가액)
차변 135 부가세대급금       (부가세)  ← 면세면 생략
대변 251 외상매입금        (공급가액 + 부가세)
```

## 자동화되지 않는 거래 (현재)

다음은 표준 패턴이 없어 사용자에게 "수동 입력 필요" 안내:

- 비용 거래 (복리후생비·접대비·통신비 등)
- 자산 취득(차량·기계·건물)
- 차입금/대여금
- 급여 (별도 PayrollEntry 테이블 사용)
- 재고 평가/감가상각
- 외환·외화 거래

위 거래는 사용자가 직접 분개 라인을 제시하면, Claude가 차변=대변 검증만 도와줍니다.

## 확장 안내

새 계정과목 추가는 `prisma/seed.ts` 수정 + `db.account.create` 사용. 사용자 요청 있을 때 Claude가 "이 계정과목은 시드에 없습니다. 추가하시려면 ..." 안내.

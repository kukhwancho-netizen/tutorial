# 사업자 유형별 규칙

본 시스템은 4가지 유형을 다룹니다. 분개·신고 일정·계산 방식이 다르므로 첫 응답에서 반드시 확인합니다.

## 매트릭스

| 유형 | 코드 | 부가세 신고 | 종소세/법인세 | 원천세 | 4대보험 |
| --- | --- | --- | --- | --- | --- |
| 법인사업자 | `CORPORATION` | 분기 (4·7·10·1월) | 법인세 3월 + 중간예납 8월 | 매월 10일 | 매월 + 보수총액 3/15 |
| 개인 일반과세 | `SOLE_GENERAL` | 반기 (7월·1월) | 종소세 5월 + 중간예납 11월 | 매월 10일 | 매월 + 보수총액 |
| 개인 간이과세 | `SOLE_SIMPLIFIED` | 연 1회 (1월) | 종소세 5월 | 매월 10일 (해당 시) | 매월 (해당 시) |
| 면세사업자 | `SOLE_TAX_FREE` | **없음** (대신 사업장현황신고 2/10) | 종소세 5월 | 매월 10일 (해당 시) | 매월 (해당 시) |

## 분기별 차이

### 법인사업자 (CORPORATION)
- 결산법인이면 법인세 신고가 핵심 (보통 12월 결산 → 3월 신고)
- 부가세 4번 (예정 2회 + 확정 2회)
- 종소세 5월 신고 안 함 — 법인세로 대체

### 개인 일반과세자 (SOLE_GENERAL)
- 가장 일반적
- 부가세 반기 2회 (1기 7월, 2기 다음해 1월)
- 종소세 5월 + 중간예납 11월
- 매출 기준 이상 → 성실신고확인 대상 → 6월말까지 연장

### 간이과세자 (SOLE_SIMPLIFIED)
- **직전 연도 공급대가 1억 400만원 미만** (2024-07-01 시행, 부가세법 개정)
  - 이전: 8천만원 미만 → 상향 조정됨
  - 단, **부동산임대업·과세유흥장소는 4,800만원 미만 기준 유지** (예외)
- **납부 면제**: 직전 과세기간 공급대가 4,800만원 미만이면 부가세 납부 자체 면제 (신고는 함)
- 부가세 연 1회만 (다음해 1/1~1/25)
- 업종별 부가가치율 적용: 소매·음식 15% / 제조·농임어업 20% / 숙박 25% / 건설·운수 30% / 서비스 40%
  - 납부세액 = 공급대가 × 부가가치율 × 10% (즉, 실효세율 약 1.5%~4%)
  - `calc_vat` 도구는 일반과세 기준이므로 간이과세는 별도 산식 필요
- 분기 예정신고 **없음** — 캘린더에서 자동 필터됨

### 면세사업자 (SOLE_TAX_FREE)
- 농·축·수·임산물, 의료·교육·금융 등
- 부가세 신고 **의무 없음**
- 대신 **사업장현황신고 2/1~2/10** (1년치 수입금액 + 계산서 합계)
- 분개 입력 시 `isTaxFree=true` 사용 — 부가세 라인 자동 생략

## 도구 호출 시 자동 판단

```
1. list_clients → 응답에서 bizType 확인
2. 후속 도구(get_tax_calendar, get_upcoming_checklist)에 그 bizType 전달
3. 결과는 이미 해당 유형에 맞게 필터됨
4. 응답을 사용자에게 보여줄 때 관련 없는 항목은 자연스럽게 생략
```

## 전환 시나리오 (안내만)

- 간이 → 일반: 직전 연도 공급대가 **1억 400만원 이상** 시 다음해 7/1부터 일반과세 적용
  - 부동산임대·유흥업소는 **4,800만원 이상** 시 일반 전환
- 일반 → 간이: 직전 연도 공급대가 **1억 400만원 미만** + 신청 → 다음해 7/1부터
  - 부동산임대·유흥업소는 4,800만원 미만 + 신청
- 본 시스템은 자동 전환 처리 안 함. 사용자가 클라이언트 정보를 수동 갱신 필요.

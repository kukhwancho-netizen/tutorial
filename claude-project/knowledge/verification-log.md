### 갱신한 항목

#### 1. 간이과세 기준액 8,000만원 → **1억 400만원**
- **시행**: 2024-07-01 부가가치세법 개정 ([정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148930428))
- **예외**: 부동산임대업·과세유흥장소는 4,800만원 기준 유지
- **수정**: `knowledge/biztype-rules.md`, `knowledge/tax-calendar.md`

#### 2. 간이과세 납부면제 4,800만원 명시
- 직전 과세기간 공급대가 4,800만원 미만이면 부가세 납부 의무 없음 (신고는 함)
- **수정**: `knowledge/biztype-rules.md`, `knowledge/tax-calendar.md`에 추가

#### 3. 국민연금 기준소득월액 (2025-07-01 ~ 2026-06-30)
- 하한: 39만원 → **40만원**
- 상한: 617만원 → **637만원**
- **출처**: [국민연금공단 고시](https://www.nps.or.kr/pnsgdnc/newgdnc/getOHAE0001M1.do?menuId=MN24000897&pstId=NE202500000000030479)
- **수정**: `src/lib/tax/rates.ts`

## 갱신 절차

다음 라운드 검증 시:
1. 본 문서의 "일치 항목"을 다시 한 줄씩 검증
2. 변경된 것은 "갱신한 항목"으로 이동 + 출처 링크 + 수정 파일 표기
3. 새 자료가 발견되면 새 섹션으로 추가
4. 검증한 날짜와 시행일을 명확히 구분 — 시행일은 정부 발표 기준, 검증일은 우리가 확인한 날

# 추가 안내 — 세액공제·경비율·발급의무 (2025년 기준)

본 시스템에 자동 반영되진 않지만, 신고 시 사용자가 알아야 할 핵심 사항.

## 1. 자녀세액공제 (2025년 신고분 인상)

기본공제 대상자 중 **8세 이상** 자녀(입양·위탁아동·손자녀 포함)에 대해:

| 자녀 수 | 공제액 | 비고 (2024 → 2025) |
| --- | --- | --- |
| 1명 | 25만원 | 15만 → 25만 |
| 2명 | 55만원 | 35만 → 55만 |
| 3명 | 95만원 | 65만 → 95만 |
| 4명 이상 | 95만 + (n-3)×40만원 | 동일 산식 |

- 본 시스템 `calc_withholding`(근로소득)은 이미 2025년 인상값 반영
- 종소세 신고 시 홈택스 화면에서 자녀 수 입력하면 자동 적용

출처: 국가법령정보센터 소득세법 / [정책브리핑 2025 연말정산 변경](https://www.korea.kr/multi/visualNewsView.do?newsId=148956909)

## 2. 전자세금계산서 의무발급 기준 (2025-07-01부터)

**대상**: 직전 과세기간(2024년) 총수입금액 **8천만원 이상** 개인사업자

**시행 흐름**:

| 시기 | 의무 기준 |
| --- | --- |
| 2022-07 | 직전연도 2억원 이상 |
| 2023-07 | 1억원 이상 |
| **2024-07 (법 개정)** | 8천만원 이상 — **2025-07-01부터 적용** |

**핵심 주의**:
- 한 번 의무 대상이 되면 **매출 변동과 무관하게 영구 의무**
- 의무 위반 시 가산세: 미발급 2% / 지연발급 1%
- 종이세금계산서 발급 시도 시 매입자 매입세액 불공제 위험

출처: [국세청 전자세금계산서 발급의무대상자](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2461&cntntsId=7787)

## 3. 의제매입세액공제 (면세 농수산물 등 매입 시)

면세품을 사 와서 과세품으로 가공·판매하는 사업자(음식점·식품제조 등)는, 매입 시 부담한 세금이 없어도 공제율로 매입세액 공제 가능.

### 업종별 공제율 (2025년 기준)

| 사업자 유형 | 공제율 |
| --- | --- |
| 음식점업 개인 (연 매출 4억 이하, 한시 2026년말까지) | **9/109** |
| 음식점업 개인 (그 외) | 8/108 |
| 음식점업 법인 | 6/106 |
| 과세유흥장소 | 2/102 |
| 제조업 (개인 중소) | 6/106 |
| 일반 (그 외) | 4/104 |

**계산식**: 매입금액 × 공제율 = 공제 매입세액

**예시**: 음식점 개인이 면세 농산물 1,090만원 매입
→ 9/109 적용: 1,090만 × 9 / 109 = 90만원 공제

본 시스템은 일반과세 부가세 계산만 자동 처리하므로, 의제매입세액공제 대상이면 사용자가 홈택스 신고 화면에서 별도 입력 필요.

출처: [부가가치세법 시행령 제84조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?lsJoLnkSeq=1000088337)

## 4. 단순경비율 vs 기준경비율 (종소세 추계신고)

장부를 기장하지 않는 개인사업자는 추계로 종합소득금액을 산정. 두 방식:

### 단순경비율 적용 대상
- 2025년 신규 사업개시자, 또는
- 직전연도(2024년) 수입금액이 **업종별 기준 미만**:
  - 도소매·농임어업·부동산매매: 6,000만원 미만
  - 제조·숙박·음식점·전기가스수도: 3,600만원 미만
  - 부동산임대·서비스: 2,400만원 미만

→ 매출 × (1 - 단순경비율) = 소득금액

### 기준경비율 적용 대상
- 단순경비율 기준을 초과하지만 복식부기 의무자가 아닌 경우

→ 매출 - (실제경비 + 기준경비율로 추계한 경비) = 소득금액

### 본 시스템에서는

`generate_income_tax_filing_guide` 도구에 `incomeAmount`(종합소득금액)를 입력해야 정확. 입력 안 하면 가이드에서 "단순/기준경비율 또는 장부로 직접 계산" 안내만 노출.

업종별 경비율 표: [국세청 공공데이터포털](https://www.data.go.kr/data/15050748/fileData.do) 매년 4월말 갱신

출처: [국세청 기장의무와 추계신고시 적용할 경비율](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2230&cntntsId=7669)

## 5. 영세사업자 부가세 납부면제 (재확인)

| 사업자 | 부가세 납부 면제 기준 |
| --- | --- |
| 간이과세자 (일반) | 직전 연도 공급대가 **4,800만원 미만** |
| 간이과세자 (부동산임대·과세유흥) | 동일 4,800만원 미만 |

신고는 해야 함. 단지 납부세액이 0.

## 권장 사용 순서 (이런 정보가 필요한 시점)

1. 거래처 등록 → 사업자번호 진위확인
2. 분개 누적
3. 신고 시즌 → `generate_xxx_filing_guide`
4. 가이드에서 안내된 화면 + **본 문서의 추가 항목**을 사용자가 홈택스에서 직접 입력
5. 전자신고 완료

# 예시 명령 — 그대로 채팅창에 붙여 쓰세요

복사 → 채팅창에 붙여넣기 → 필요하면 숫자/이름만 바꿔 사용.

## 일정 확인

```
샘플상사 다음 30일 안에 마감되는 거 다 보여줘
```

```
이번 달에 내가 챙겨야 할 신고·납부 항목 알려줘
```

```
법인사업자 부가세 1기 예정신고 언제까지야? 안 하면 어떻게 돼?
```

## 즉석 계산

```
매출 공급가액 3천만원, 매입 1천만원이면 부가세 얼마야?
```

```
사업소득금액 8천만원, 부양가족 본인+배우자+자녀1명 종소세 계산해줘
```

```
프리랜서한테 150만원 줄 건데 원천세 떼고 얼마 지급해야 해?
```

```
월급 320만원 받는 직원 4대보험 근로자/사업주 부담분 각각 얼마?
```

## 분개 입력 (영수증 사진 첨부)

📎 영수증 사진 첨부 + 아래 메시지

```
이거 샘플상사 매입으로 넣어줘
```

```
이 세금계산서로 분개해줘. 매출이야
```

```
영수증 3장 다 분개해서 저장해
```

## 분개 입력 (자연어)

```
샘플상사 5월 12일 ABC상사한테 100만원 매출, 현금
```

```
샘플상사 어제 사무용품 5만원 샀어. 면세
```

```
샘플상사 외상으로 300만원 매입 들어왔어, 거래처 XYZ
```

## 신고 자료 / 집계

```
샘플상사 2026년 1기 부가세 신고 자료 정리해줘
```

```
이번 분기 매출 매입 합계 보여줘
```

```
1월부터 지금까지 누적 납부세액 얼마야?
```

## 회계 상담

```
차량 1500만원 일시불로 샀으면 어떻게 분개해?
```

```
외상매입금 결제하면 분개가 어떻게 돼?
```

```
이번 거래 어느 계정과목에 넣어야 해? "구글 광고비 50만원"
```

## 복합 (가지 이동)

```
샘플상사 이번 달 마감 뭐 있는지 보고, 그 중에 종소세 있으면 사업소득 7천만 기준으로 미리 계산해줘
```

```
어제 거래 다 보여주고, 누락된 영수증 있을 만한 거 짚어줘
```

```
1분기 마감 임박했어. 부가세 자료 정리하고, 예상 납부세액이랑 자금 확보 필요한지 알려줘
```

## 첫 사용 시 권장 멘트

새 Project 만들고 처음 대화할 때:

```
지금 어떤 도구가 연결돼 있어? list_clients 호출해서 내 거래처도 확인해줘
```

→ MCP가 연결됐는지, 어느 사용자로 인증돼 있는지 한 번에 확인.

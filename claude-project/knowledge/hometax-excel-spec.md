# 홈택스 엑셀 임포트 — 필요한 파일 스펙

본 시스템에 데이터를 빠르게 채우려면 홈택스에서 다음 파일을 다운로드해 업로드:

## 1. 매출처별 세금계산서 합계표

**홈택스 경로**: 신고/납부 → 부가가치세 → 신고 도움 자료 → 매출처별 세금계산서 합계표 (또는) 전자세금계산서 → 합계표 다운로드

**다운로드 형식**: XLSX 또는 CSV

**필수 컬럼**:
- 거래일자 (또는 작성일자/발급일자/일자)
- 거래처 (또는 매출처/상호/공급받는자)
- 공급가액 (또는 과세표준)

**선택 컬럼** (있으면 더 정확):
- 사업자등록번호
- 세액 (또는 부가세)
- 합계금액

## 2. 매입처별 세금계산서 합계표

동일한 구조. 시트명이나 헤더에 "매입"이 있으면 자동으로 매입 분개로 저장.

## 3. 카드/현금영수증 매출 내역 (필요 시 별도 시트로 변환)

홈택스 현금영수증 발행내역은 컬럼이 살짝 다르니, 다음 형식으로 정리해 업로드:

| 거래일자 | 거래처 | 공급가액 | 세액 |
| --- | --- | --- | --- |
| 2026-05-01 | (현금/카드 결제 식별 가능한 이름) | 100,000 | 10,000 |

## 업로드 절차

1. **로컬 앱**: `/clients/[id]/import` 페이지 진입 → 파일 선택 → 미리보기 → 확인 후 저장
2. **Claude.ai 채팅**: 파일을 채팅창에 첨부 → "샘플상사 매출로 일괄 임포트해줘" → Claude가 행을 읽고 `bulk_create_journal_entries` MCP 도구로 일괄 전송

## 자동 처리 규칙

- 빈 행은 무시
- 거래일자 누락 행은 에러 표시, 나머지는 진행
- 부가세가 공급가액의 10%와 크게 차이나면 ⚠️ 경고 (저장은 진행)
- 부가세가 0이면 면세 거래로 저장 (isTaxFree=true)
- 결제 방법은 일괄 CASH로 저장 (외상 구분이 필요하면 차후 개별 수정)
- 1000건 초과는 파일을 나누어 업로드

## 미지원 / 주의

- ❌ 자동 사업자번호 진위확인 (`verify_biz_no` 도구로 별도 호출)
- ❌ 신용카드 매출 vs 현금영수증 매출 자동 분리 (별도 시트로)
- ❌ 면세/과세 자동 판별은 부가세 0 여부로만 결정 — 의제매입세액공제 등은 수동
- ⚠️ 이미 등록된 분개와 중복 검사 안 함 — 중복 업로드 시 같은 거래가 두 번 저장될 수 있음. 업로드 전 기존 분개 점검 권장.

## Claude 채팅 사용 예시

```
[파일 첨부: 매출_세금계산서_합계표.xlsx]

샘플상사 매출로 일괄 임포트해줘.
```

→ Claude는 파일을 직접 읽고 행별로 위 컬럼을 추출 → `bulk_create_journal_entries` 한 번 호출 → 결과 요약(성공/실패 건수, 실패 행 사유)을 반환.

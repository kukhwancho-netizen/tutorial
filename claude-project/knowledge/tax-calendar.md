# 한국 세무 일정 (2025년 귀속 / 2026년 신고분 기준)

본 문서는 `src/lib/tax/calendar.ts`의 데이터를 사람이 읽기 좋게 정리한 것입니다. MCP가 연결된 경우 `get_tax_calendar` 도구가 더 정확한 동일 정보를 반환합니다.

## 부가가치세

| 항목 | 신고기간 | 적용 |
| --- | --- | --- |
| 법인 1기 예정 | 4/1 ~ 4/25 | 법인사업자 (1~3월 실적) |
| 법인 1기 확정 / 개인 1기 | 7/1 ~ 7/25 | 법인 4~6월 / 개인 일반 1~6월 |
| 법인 2기 예정 | 10/1 ~ 10/25 | 법인사업자 (7~9월 실적) |
| 법인 2기 확정 / 개인 2기 | 다음해 1/1 ~ 1/25 | 법인 10~12월 / 개인 일반 7~12월 |
| 간이과세자 부가세 | 다음해 1/1 ~ 1/25 | 1년치(1~12월), 연 1회 |

간이과세자는 분기 예정신고 없음. 면세사업자는 부가세 신고 의무 없음(아래 사업장현황신고).

## 사업장현황신고 (면세사업자)

- **기간**: 매년 2/1 ~ 2/10
- **대상**: 면세사업자
- **내용**: 1년치 수입금액 + 매출·매입 계산서 합계표

## 종합소득세 / 법인세

| 항목 | 신고기간 | 적용 |
| --- | --- | --- |
| 종합소득세 정기신고 | 5/1 ~ 5/31 | 개인사업자 + 종합소득 보유자 |
| 종소세 성실신고확인 대상 | ~ 6/30 | 일반과세자 중 업종별 매출 기준 이상 |
| 종소세 중간예납 | 11/1 ~ 11/30 | 전년 산출세액의 50%가량 |
| 법인세 신고 (12월 결산) | ~ 3/31 | 결산일 후 3개월 이내 |
| 법인세 중간예납 | ~ 8/31 | 사업연도 개시 6개월 후 2개월 이내 |

## 원천세

- **원천징수이행상황신고서**: 지급한 달의 **다음달 10일까지** 매월
- **반기별 납부 신청 대상자**: 1/10, 7/10 (연 2회로 갈음)
- **근로소득 연말정산**: 매년 2월(전년도분) — 3/10까지 신고

### 세율 요약

| 소득 종류 | 원천세율 |
| --- | --- |
| 사업소득(프리랜서) | 3.3% (소득세 3% + 지방세 0.3%) |
| 기타소득 일반 | 8.8% (필요경비 60% 의제 후 22%) |
| 근로소득 | 국세청 간이세액표 — 월급여·부양가족 수에 따라 |
